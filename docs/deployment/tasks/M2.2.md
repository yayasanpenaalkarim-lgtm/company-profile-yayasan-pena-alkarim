## Detailed implementation instructions

1. Preserve clients: PUBLIC_SUPABASE_URL and PUBLIC_SUPABASE_ANON_KEY are build inputs for browser and SSR. Runtime-only Worker changes cannot repair an incorrectly compiled client.

2. Make empty .env.example trackable while real .env/.env.* remain ignored. Do not add credentials.

3. Implement dependency-free validator and validate:env script; explicitly load approved local .env or CI process env without logging values. Reject missing/whitespace variables, malformed URL, secret/service-role key and wrong project identity.

4. Define fail-closed target modes local/staging/production. Local permits loopback only; remote modes require approved project mapping. Validate supported public-key formats against official guidance; decoded claims alone are not full validation.

5. Document secure injection and per-target rebuilds. Cloudflare deployment credentials belong only in the deploy step. Exercise positive and negative cases without making network requests.
